# FetchIt

## Description 

An extension for quickly moving trough your active files. Inspired by
[Harpoon by ThePrimeagen](https://github.com/ThePrimeagen/harpoon)

(This extension is mostly for my self xD, you should probably find better alternatives)

## Features

- Add files to your active list 

- Move back and forth trough the files

- Only use your keyboard to navigate your files

## Keybinds

- Adding a file to the active list - Alt+a

- Open the active file list - Alt+e

- Go to the next file - ctrl+] (cmd+])

- Go to the previouse file - ctrl+[ (cmd+])

- Remove all files from active list - Alt+r

**Enjoy!**
